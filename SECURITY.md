# Reporting a security issue

This is a locally verified research/portfolio application, not a publicly operated privacy service. Review [security controls and limitations](docs/SECURITY_AUDIT.md) and [release readiness](docs/RELEASE_READINESS.md) before hosting it with private data.

Do not post passwords, database URLs, cookies, pairing codes, device credentials, scan exports or exploit details in a public issue. A public repository and private reporting channel have not been provisioned. Before publication, the maintainer should enable GitHub private vulnerability reporting and publish a verified contact channel. Until then, share a minimal redacted report privately with the person who supplied this project.

Useful report details: affected source version, sanitized reproduction steps, expected/actual behavior, and impact. Do not test another person's account or a third-party service. No support window or vulnerability-response SLA is promised for this pre-release project.
